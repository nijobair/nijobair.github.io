    22 / DOCUMENT HEAD

    Non-Visual Elements

    Some HTML elements belong in the document head or have no visible representation.

    • <base> establishes the base URL.
    • <link> connects external resources.
    • <meta> provides document metadata.
    • <style> contains CSS.
    • <script> contains or references JavaScript.
    • <noscript> provides fallback content when JavaScript is disabled.
    • <template> stores inert markup for later use.
